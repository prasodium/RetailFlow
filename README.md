# RetailFlow

RetailFlow is a full-stack Retail Sales & Inventory Intelligence Platform.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL

### Planned Technologies
- Redis
- Docker
- GitHub Actions

## Core Features

- User authentication
- Role-based access control
- Product management
- Retailer management
- Inventory management
- Order management
- Payment tracking
- Returns
- Sales visits
- Analytics
- Offline-first PWA
